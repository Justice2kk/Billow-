# Your first little Billow page

A tiny starting point: just **HTML + CSS**.

| File | What it does |
| --- | --- |
| [`index.html`](index.html) | Headings, text and the page structure. |
| [`styles.css`](styles.css) | Layout, color, spacing and responsive styling. |

### Play with it

1. Open [the HTML file](index.html) and change the heading or paragraph.
2. Open [the CSS file](styles.css) and try a different `background-color` or `padding`.
3. Compare what you changed with the [Billow HTML](../../../docs/web/HTML.md) and [CSS](../../../docs/web/CSS.md) profiles.

This is **readable learning/conformance source**, not an installable website template or a published site. The full Sites journey exists in internally accepted builds, but this public example does not invent a manifest, CLI or one-click import process.
