### How to read support labels

**Supported** means the documented feature works within the stated contract. **Supported with limits** means it works differently or covers only part of the familiar feature. **Experimental** can change. **Unsupported** is not currently available. **Billow-native** means we aren't claiming equivalence to another platform.

The [compatibility index](compatibility/FEATURES.md) is generated from [the feature registry](../compatibility/registry.json). It is the detailed source for feature claims, not a promise of complete browser standards support.
